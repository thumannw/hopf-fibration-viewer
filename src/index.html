Geometry & controls

This explorer uses h(q) = qiq⁻¹ and right multiplication q exp(ti). For q = a + bi + cj + dk, stereographic projection is (x, y, z) = (c, d, b) / (1 + a). Thus 1 maps to the origin, and −1 to infinity.

The base sphere has coordinates (j, k, i). North (+i) corresponds to the z-axis. South (−i) corresponds to the unit circle in the x-y plane. All other fibres are exact planar circles.

All selections use the same circle controls. Add a circle, select its numbered entry, and optionally enter a name in the editor. Clear the name to return to a numbered entry. Names are saved with the configuration. The family examples use these same controls.

Circles use axis azimuth (0° = +X, 90° = +Y), elevation above the XY plane, and a signed centre offset from −1 to +1. Offset 0 gives a great circle; at either endpoint it collapses to one point and one fibre. Arc settings are retained while disabled. Start 0° is the circle point nearest north; positive angles follow the right-hand rule about the positive axis. At exactly vertical axes, azimuth is ignored and retained, and start 0° uses +X. This fixed pole convention can change the arc reference abruptly on reaching a vertical axis. Angular sweep is measured around the circle, so 180° always selects half of it.

Points are equally spaced in arc length on the selected base circle. Full circles do not repeat the endpoint. Partial arcs include both endpoints when checked, and use interval midpoints otherwise. Shared points are merged. Circles at offset ±1 collapse to one point.

The root disc is a coordinate model of the base: its entire boundary represents south. If θ is colatitude on S², the root-disc radius is r = tan(θ/4). Equal radial steps in the disc are not equal angular steps on the sphere.

The viewing sphere clips fibre centre-lines analytically. Small beads mark clipping endpoints; these are not physical joints. Tubes have a visual thickness and may overlap if made too thick. The north fibre is a line, never a large fake circle. Changing geometry preserves the camera; use Fit when needed.

Drag either view to rotate it. Scroll or pinch to zoom. Right-drag pans the fibre view. Keyboard: focus a canvas and use arrow keys to orbit, +/− to zoom, and Home to reset or fit. The fibre menu offers keyboard selection.

Base rotation applies the same left quaternion action to all selections: h(aq) = a h(q) a⁻¹. X corresponds to exp(θj/2), Y to exp(θk/2), and Z to exp(θi/2), where θ is the angle on the base sphere. Speed is measured in degrees per second on the base sphere. Axis changes continue from the current orientation about the fixed base axes. Reverse changes the direction. Reset orientation pauses and restores the original arrangement without changing the circle definitions or cameras. Colours and selected fibres travel with their points. Playback pauses when the page is hidden.

The rotation dial shows the angle of the current step modulo 360°. Each axis change preserves the pose and resets the dial to 0°. Setting the dial back to 0° restores the pose at the start of this step. Drag or touch the dial, or enter degrees, to pause playback and adjust the viewers immediately. Arrow keys adjust by 1° (Shift: 10°); Page Up/Down by 15°; Home sets 0° and End sets 359°. Negative angles and complete turns wrap around.

Rotated latitude circles need not remain latitudes. Selection controls always describe the original geometry; the fibre inspector reports current coordinates. The reference sphere, guides, pole labels, and cameras stay fixed. Use Fit or zoom out to leave room for fibres that grow near north.

Save configuration downloads a JSON file including geometry, rotation settings and both cameras. Loading always pauses playback. Configurations use version 4 and store the circle settings and optional names. The HTML works offline without installation or network requests. Rendering requires a browser with WebGL 2 support.
